## 📖 Tentang Game

**PAKDE ADVENTURE** adalah game platformer 2D berbasis web yang dibuat sebagai proyek hiburan dan eksperimen pengembangan game. Pemain mengendalikan karakter Pakde dalam petualangan melewati rintangan, mengumpulkan koin, menghindari musuh, dan mencapai garis finish.

Game ini mengusung visual **pixel art** dengan latar tempat ikonik Indonesia, menghadirkan petualangan bergaya retro dengan sentuhan lokal yang unik.

Tujuan utamanya sederhana: bantu Pakde menyelesaikan setiap level dan melanjutkan petualangannya menuju puncak kekuasaan di Indonesia!

## ✨ Fitur Utama

- 🕹️ **Gameplay Platformer 2D** — Bergerak, melompat, melewati rintangan, dan mencapai garis finish.
- 🇮🇩 **Latar Ikonik Indonesia** — Petualangan dengan latar Monumen Nasional, Gedung DPR RI, dan Istana Presiden.
- 🪙 **Sistem Koin dan Skor** — Kumpulkan koin dan raih skor setinggi mungkin.
- ❤️ **Sistem Nyawa** — Kelola nyawa agar Pakde dapat menyelesaikan level.
- 🍄 **Power-up Jamur** — Manfaatkan jamur untuk mendukung perjalanan karakter.
- ❔ **Blok Tanda Tanya** — Temukan elemen interaktif selama bermain.
- 👾 **Musuh dan Rintangan** — Hindari bahaya yang dapat menghambat perjalanan.
- 🔊 **Efek Suara dan Audio** — Nikmati audio untuk meningkatkan pengalaman bermain.
- ⏸️ **Pause dan Lanjutkan** — Jeda permainan dan lanjutkan saat siap.
- 🏆 **Best Score** — Pantau pencapaian skor terbaik.
- 📱 **Kontrol Mobile** — Gunakan tombol kontrol di layar pada perangkat yang mendukung.
- 🎨 **Visual Pixel Art** — Tampilan retro dengan desain yang terinspirasi dari game klasik.

## 🎮 Cara Bermain

1. Buka game melalui tautan **Mainkan Sekarang**.
2. Klik **Mulai Game** untuk memulai petualangan atau pilih level yang tersedia.
3. Gerakkan Pakde untuk melewati rintangan.
4. Kumpulkan koin dan raih skor sebanyak mungkin.
5. Hindari musuh agar nyawa tidak habis.
6. Manfaatkan power-up dan elemen interaktif yang ditemukan.
7. Capai garis finish untuk menyelesaikan level dan melanjutkan petualangan.

### Kontrol Permainan

| Aksi              | Keyboard         | Perangkat Mobile                   |
| ----------------- | ---------------- | ---------------------------------- |
| Bergerak ke kiri  | `←` atau `A`     | Tombol kiri                        |
| Bergerak ke kanan | `→` atau `D`     | Tombol kanan                       |
| Melompat          | `SPACE` atau `↑` | Tombol lompat                      |
| Pause / lanjutkan | `ESC`            | Gunakan kontrol jeda yang tersedia |

## 🛠️ Teknologi

PAKDE ADVENTURE dibuat menggunakan teknologi web standar, tanpa memerlukan framework frontend untuk menjalankan game.

| Teknologi    | Penggunaan                                                        |
| ------------ | ----------------------------------------------------------------- |
| HTML5        | Struktur halaman dan elemen game                                  |
| CSS3         | Tampilan, layout, animasi, dan desain responsif                   |
| JavaScript   | Logika permainan, pergerakan karakter, interaksi, dan sistem skor |
| HTML5 Canvas | Rendering area permainan                                          |
| GitHub Pages | Hosting game secara online                                        |

## 🚀 Menjalankan Secara Lokal

PAKDE ADVENTURE dapat dijalankan langsung melalui browser tanpa instalasi dependensi npm.

### 1. Clone repository

```bash
git clone https://github.com/MaulanaHidayatulloh/Game-PAKDE-ADVENTURE.git
```

### 2. Masuk ke direktori proyek

```bash
cd Game-PAKDE-ADVENTURE
```

### 3. Jalankan game

Buka file `index.html` menggunakan browser modern.

Untuk pengalaman pengembangan yang lebih baik, kamu dapat menggunakan ekstensi **Live Server** di Visual Studio Code, lalu jalankan `index.html` melalui server lokal.
